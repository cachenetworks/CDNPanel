# CDNPanel Licensing Guide

This guide explains the CDNPanel license in plain English.

It is provided for convenience only. The full [LICENSE](LICENSE) controls if there is any conflict.

## What kind of license is CDNPanel using?

CDNPanel uses the **Cache Networks Source-Available Personal & Community Contribution License v2.0**.

It is **source-available**, not open source.

That means you can read the source, learn from it, use it personally, modify it privately, and fork it to help improve CDNPanel — but you do **not** receive unrestricted redistribution or commercial rights.

## Can I use CDNPanel for free?

Yes, for personal, non-commercial use.

Examples:

- your own home lab;
- your own personal server;
- your own private development environment;
- your own non-commercial hobby project;
- your own personal site serving files you control.

The fact that visitors can download files from your personal non-commercial project does not by itself make the deployment prohibited.

What you cannot do is turn CDNPanel into a service for other people by giving them things like:

- accounts;
- tenants;
- upload access;
- storage allocations;
- API keys;
- file-management access;
- managed CDN functionality;
- administrative access.

## Can I modify it?

Yes, for personal, non-commercial use.

You can:

- change the UI;
- add features;
- edit the API;
- experiment with storage;
- modify deployment files;
- build your own private version.

You cannot publish that modified version as an independent CDNPanel distribution unless Cache Networks gives you written permission.

## Can I fork it on GitHub?

Yes.

Community forks are explicitly allowed for genuine project-development work.

That includes:

- pull requests;
- fixes;
- features;
- refactors;
- tests;
- documentation;
- bug reproduction;
- code review;
- performance work;
- experiments intended to help CDNPanel.

Your fork must remain clearly connected to CDNPanel and cannot be turned into your own competing product or independent distribution.

## Can my fork be public?

Yes, when it is a normal GitHub community fork used for contribution and development.

Keep the license and attribution intact.

Do not rebrand the fork as though you created CDNPanel.

## Can I release my fork as my own product?

No.

Not without written permission from Cache Networks.

That includes:

- a renamed CDNPanel;
- a white-label version;
- your own release channel;
- your own downloadable build;
- your own Docker images;
- a competing project based on CDNPanel;
- a mirror intended to act as another distribution source.

## Can I publish Docker images or packages?

Not independently.

You may build them privately for testing or personal use.

Publishing CDNPanel-derived images, installers, packages, bundles, or binaries requires written permission unless Cache Networks itself is publishing them.

## Can I run it for my business?

Not under the default license.

Business and organisational use require written permission or a separate license.

This applies even when the organisation is non-profit.

## Can I use it for a Discord community or other group?

If the instance is being operated as a shared service for a community, organisation, club, customers, or users other than your own personal project, that normally falls under organisational or hosted-service use and requires permission.

A GitHub fork used only to help contribute code back to CDNPanel is still allowed.

## Can I sell CDNPanel?

No.

You may not sell, sublicense, resell, lease, monetise, or package CDNPanel commercially without written permission.

## Can I host CDNPanel for customers?

No.

Running CDNPanel as a paid or managed service for third parties requires written permission.

## Can I copy code from CDNPanel into my own project?

Do not assume that public source means unrestricted copying.

If you copy protected CDNPanel code into another project, you need permission unless the use is already expressly allowed by the license.

Where permission exists, copied or adapted protected code must retain attribution.

The recommended attribution is:

```text
Contains code derived from CDNPanel by Cache Networks.
Copyright (c) 2026 Cache Networks.
Original project: https://github.com/cachenetworks/CDNPanel
Used under the Cache Networks Source-Available Personal &
Community Contribution License.
```

## What does "copied code" mean?

The license refers to a **Covered Excerpt**.

That can include:

- non-trivial source lines;
- functions;
- classes;
- components;
- schemas;
- configuration blocks;
- documentation passages;
- other identifiable copyrightable expression.

Simply learning a technique or independently implementing the same general idea does not automatically mean you copied CDNPanel.

The license does not claim ownership over facts, ideas, general algorithms, short names, public concepts, or independently created code that copyright law does not protect.

## What if I change variable names or rewrite the code?

Changing formatting, renaming variables, translating to another language, splitting a function, or making cosmetic edits does not automatically remove the attribution requirement if you are still adapting protected CDNPanel expression.

## Can I claim my modifications are mine?

You own your original code to the extent the law gives you ownership of it.

You do not gain ownership over Cache Networks code simply because you modified it.

A fork should not claim that the original CDNPanel code was authored by you.

## What happens when I submit a pull request?

You keep ownership of your original contribution.

By intentionally submitting it to CDNPanel, you grant Cache Networks a broad, perpetual license to use, modify, distribute, sublicense, relicense, and include that contribution in future CDNPanel and related Cache Networks work.

This is necessary so the project can continue evolving without having to contact every contributor for permission before every future release.

Read Section 5 of the full [LICENSE](LICENSE) for the exact terms.

## Can Cache Networks change the license later?

Future releases can be published under revised terms.

A future change does not automatically rewrite the terms attached to an older copy that was previously distributed under an earlier version, except where applicable law or those earlier terms say otherwise.

## Can Cache Networks offer a commercial license?

Yes.

The default public license deliberately reserves that option.

Cache Networks can separately grant:

- business use;
- commercial use;
- hosted-service rights;
- redistribution rights;
- OEM rights;
- white-label rights;
- educational exceptions;
- non-profit exceptions;
- custom licensing.

Those permissions must be granted separately in writing.

## Is CDNPanel open source?

No.

The source is visible and contribution-friendly, but the redistribution and commercial restrictions mean it is not an OSI-style open-source license.

## Why use this model?

The goal is to allow people to:

- inspect the code;
- learn from it;
- self-host it personally;
- experiment;
- contribute improvements;
- submit fixes;
- help the project grow;

while preventing people from:

- cloning the project and claiming it as their own;
- creating competing CDNPanel distributions;
- removing attribution;
- reselling it;
- rebranding it;
- mirroring it as an alternative product;
- operating commercial hosted versions without permission.

## What if I am unsure?

If your intended use involves:

- a business;
- an organisation;
- customers;
- paying users;
- public accounts;
- redistribution;
- packages;
- Docker images;
- rebranding;
- white-label use;
- incorporation into another distributed product;
- a hosted service;

assume you need written permission unless the full license clearly says otherwise.

For the legally controlling terms, always read the complete [LICENSE](LICENSE).
